# Security policy

## Supported versions

Security and privacy fixes are provided for the latest released version of
BreakBar. Upgrade to the newest release before reporting an issue that may
already have been fixed.

## Reporting a vulnerability

Please do not open a public issue for a suspected security or privacy
vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/allenhutchison/breakbar/security/advisories/new)
so the report and any sensitive details remain private.

Include the affected BreakBar and macOS versions, reproduction steps, expected
and observed behavior, and the security or privacy impact. Remove credentials,
calendar titles, personal file paths, and other unrelated personal data from
logs or screenshots before attaching them.

Relevant reports include vulnerabilities involving the signed update channel,
local history or settings, calendar and call-state access, Obsidian export, or
privilege and sandbox boundaries. Ordinary bugs and feature requests belong in
the public issue tracker.
