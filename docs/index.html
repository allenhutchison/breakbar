Built for real workdays

A timer that notices what is happening.

01

Meeting-aware

Selected calendars and active calls keep BreakBar from interrupting a meeting. When a meeting runs over, the timer waits too.

02

Hard to overlook

A warning, sound, and full-screen prompt make the transition visible. A floating return panel stays present while you are away.

03

Your day, recorded

See today’s focus, meeting, lunch, travel, and break time. Correct clock-in times or classifications when the day changes shape.

Private by design

Your workday stays on your Mac.

BreakBar stores its timer state and history locally. It reads only the calendars you select, never edits events, and does not store calendar titles in timer history.

Call detection checks whether a recognized app is using microphone input. BreakBar never records or listens to microphone audio.
